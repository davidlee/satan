# Running pi from a host shell: PI_BIN and PI_MODEL are two separate environment axes

Which pi and which provider are independent. Outside a jail, bare pi holds no gateway credential, so the correct default is PI_BIN=jailed-pi (the jail supplies the key and the model catalog) and PI_MODEL is then unnecessary; inside a jail, leave PI_BIN unset because jailed-pi is on PATH and would nest. Separately: pi --list-models showing only deepseek plus 'No models match pattern llm-gateway/...' is a provider-REGISTRATION symptom of LLM_GATEWAY_KEY missing from that shell (positive control: env -u LLM_GATEWAY_KEY reproduces it, exporting the key fixes it), not a broken models.json and not a missing gateway. Both axes are explicit, never detected: detection mis-fires in both directions.
